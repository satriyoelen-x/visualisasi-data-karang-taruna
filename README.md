# visualisasi-data-karang-taruna
Project Data Visualizationkeaktifan pemuda Karang Taruna 
Proyek ini merupakan tugas mata kuliah Data Mining yang berfokus pada penerapan visualisasi data menggunakan Python. Dataset yang digunakan berisi informasi anggota Karang Taruna untuk membantu memahami pola keaktifan dan partisipasi anggota dalam kegiatan organisasi.

Tujuan: 

Memahami karakteristik dataset anggota Karang Taruna.
Mengolah dan mengelompokkan data menggunakan Pandas.
Menyajikan informasi melalui visualisasi menggunakan Matplotlib.
Mengidentifikasi pola distribusi usia, komposisi jenis kelamin, status keaktifan, dan kehadiran anggota.

Tools dan Library : 

Python
Pandas
Matplotlib
OpenPyXL

Tahapan Pengerjaan : 

Membaca dan memeriksa dataset.
Memeriksa nilai kosong dan duplikasi.
Membuat kolom turunan untuk analisis kelompok usia.
Melakukan agregasi data menggunakan value_counts() dan groupby().
Membuat grafik batang, diagram lingkaran, dan histogram.
Menambahkan judul, label sumbu, grid, serta informasi nilai pada grafik.
Menginterpretasikan hasil visualisasi.
Visualisasi

Visualisasi yang direncanakan meliputi : 

Jumlah anggota berdasarkan status keaktifan.
Jenis kelamin anggota.
Usia anggota.
Rata-rata kehadiran berdasarkan dusun.

Hasil dan Kesimpulan

Hasil visualisasi digunakan untuk memahami distribusi anggota dan membandingkan tingkat partisipasi antar kelompok.
